Prompt

Beschreib, was entstehen oder sich ändern soll, zum Beispiel „Leg eine Bubble Urlaub mit drei Unterpunkten an“ oder „Ordne die markierten Bubbles unter Materialien ein“. Rückgängig nimmt alles auf einmal zurück.

Strg/Cmd + Enter
    API-Schlüssel

    Der Prompt-Reiter fragt Claude mit deinem eigenen Anthropic-API-Schlüssel (console.anthropic.com). Er bleibt nur in diesem Browser gespeichert und wird nur an api.anthropic.com geschickt.

    Einstellungen

    Wirken sofort und werden in diesem Browser gespeichert.

    Gespeichert

    Klick auf einen Namen lädt ihn. „Standard“ gilt beim Öffnen und für „Standard wiederherstellen“.
